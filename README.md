# 네이버 블로그 매물 자동화 (vibe-blogpost)

매물번호 하나로 매물 조사 → 블로그 원고 생성 → 대표 이미지 → 네이버 블로그
포스팅까지 이어 주는 공인중개사용 로컬 프로그램입니다. (macOS · Windows)

> 2026-08-12 갱신 — 예전 README 에 있던 "코중사제출용 프로그램" 폴더 경로는
> 2026-07 임시 작업 폴더의 흔적으로, 이 프로그램과 무관합니다. 지금은
> 이 폴더(설치한 위치)가 곧 프로그램 폴더입니다.

## 실행

- **macOS**: `run.command` 더블클릭 (첫 실행 때 전용 환경을 자동 구성 — 인터넷 필요, 몇 분)
- **Windows**: `run.bat`
- 크롬(Chrome)이 설치돼 있어야 합니다.

## 사용 순서 (왼쪽 단계 버튼)

1. **매물 조사하기** — 매물번호를 넣거나 '내 매물' 탭에서 클릭하면 매물 자료를 수집해
   '매물 조사 메모'에 정리합니다.
2. **AI로 자동 글쓰기** — 조사 자료로 제목·본문·해시태그를 만들어 'blog자료' 탭에 채웁니다.
   (외부 AI를 직접 쓰고 싶으면 4. 프롬프트 생성 → 5. 결과 붙여넣기 경로도 있습니다)
3. **블로그로 포스팅** — 화면에서 검토·수정한 글을 네이버 블로그에 올립니다.
   환경설정에서 임시저장/즉시발행, 공개범위(비공개·전체공개), 카테고리를 정할 수 있습니다.

## 처음 한 번만 설정할 것 (환경설정 탭)

- 중개사무소 정보(상호·연락처 등)와 네이버 아이디
- 내 중개사 ID — '내 매물' 탭이 내 매물만 골라 보여주는 데 씁니다
- Google AI Studio API Key (AI 자동 글쓰기용 · 선택)
- 첫 포스팅 때 네이버 로그인 창이 뜨면 직접 로그인 1회 — 이후는 기억됩니다

## 알아둘 것

- 대표 이미지는 이 컴퓨터에서 생성되며, 홍보 이미지에는 지번·호수가 표시되지 않습니다.
- 프로그램은 시작할 때 새 버전을 자동 확인하고, 다음 실행 때 스스로 업데이트됩니다.
  (입력해 둔 계정·설정·로그인 세션은 보존됩니다)
- API 키·비밀번호는 운영체제 보안 저장소(keyring)와 이 폴더의 `.env` 에만 저장되며
  배포 파일에는 포함되지 않습니다.
