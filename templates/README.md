# 이미지 템플릿

선택 참조 이미지:

`templates/썸네일가이드.png`

파일이 있으면 프로그램은 1:1로 맞춘 뒤 중앙 카드 영역을 새 배경으로 덮어 기존 문구가
섞이지 않게 하고, 가이드의 바깥 여백·질감을 참고합니다. 파일이 없으면 이미지 탭의
색상 프롬프트를 사용해 다크 네이비 기본 디자인을 만듭니다.

전화 배너와 거래상태 확인 이미지는 임시저장 직전에 비용 없이 자동 생성합니다.

```text
templates/전화연결배너.png
templates/거래완료경고.png
```

`거래완료경고.png`라는 호환 파일명을 사용하지만 실제 문구는 “매물 상태는 수시로
변경될 수 있으므로 계약 전 다시 확인”하라는 안내입니다. 특정 매물이 이미 거래
완료됐다고 단정하지 않습니다. 사용자가 같은 파일명으로 직접 만든 파일이 있어도 현재
프로그램은 개인정보나 오래된 번호가 남지 않도록 실행 시 최신 문의번호로 다시 생성합니다.
