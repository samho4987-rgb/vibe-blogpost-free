🏠 빠른 시작 안내

네이버 블로그 매물 자동화 프로그램을 처음 쓰는 분을 위한 3분 가이드입니다.

준비물

인터넷 연결과 파이썬 3.11 이상이 필요합니다. 파이썬이 없다면 python.org에서 먼저 설치해 주세요. (실행파일 .exe로 받은 경우에는 필요 없습니다.)
🪟 Windows🍎 macOS

1단계 · 처음 한 번만 설치

1

설치 파일 실행

Windows: scripts 폴더의 setup.bat 더블클릭
macOS: scripts 폴더의 setup.command 더블클릭
검은 창이 뜨고 자동으로 설치됩니다. "설치가 끝났습니다"가 보이면 닫습니다.

macOS에서 "확인되지 않은 개발자" 경고가 나오면, 파일을 마우스 오른쪽 클릭 → 열기를 선택하면 실행됩니다.

2단계 · 프로그램 켜기

2

실행 파일 더블클릭

Windows: run.bat  ·  macOS: run.command
프로그램 창이 열립니다.

3단계 · 키 입력 (처음 한 번)

3

환경설정 탭

환경설정 탭에서 네이버 로그인 정보와 필요한 API 키를 넣고 저장합니다. AI 자동 글쓰기를 안 쓸 거면 Google 키는 비워도 됩니다.

4단계 · 글 만들고 올리기

4

매물번호 → 조사 → AI 글쓰기 → 포스팅

① 매물번호 입력(또는 내 매물 탭에서 더블클릭) → 매물 조사하기
② AI로 자동 글쓰기 → 제목·본문·대표 이미지 자동 생성
③ 내용 확인 후 블로그로 포스팅

작업 흐름 자세히

  1. 좌측에서 매물번호를 직접 입력하거나, 내 매물 탭에서 크롤링된 매물 CSV 폴더를 지정하고 매물을 더블클릭하면 매물 조사하기가 실행됩니다. 이때 네이버 매물 내용은 물론 건축물대장 정보와 주변 입지 정보까지 함께 가져옵니다.
  2. AI로 자동 글쓰기를 누르면 미리 설정된 기준에 따라 blog자료 탭에 블로그 제목·본문과 대표 이미지 1개를 만듭니다.
  3. 블로그로 포스팅을 누르면 자동으로 네이버에 로그인하고 정해진 카테고리에 포스팅합니다.
  4. (선택) 대신 본문용 프롬프트·이미지 생성 프롬프트를 만들어, 다른 AI 프로그램으로 제목·본문·이미지를 제작해 올 수도 있습니다.
  5. (선택) 그 결과를 붙여넣어 본문과 이미지를 완성한 뒤 블로그로 포스팅하는 방법도 있습니다.
✅ 기본은 임시저장이라 글이 바로 공개되지 않습니다. 발행(전체공개)은 환경설정에서 발행 모드를 켜고 카테고리 이름을 정확히 넣어야 진행됩니다.
🔒 프로그램을 다른 사람에게 줄 때는 .env, config/user_settings.json, data/browser-profile 폴더를 함께 주지 마세요. 내 계정·키·로그인 세션이 들어 있습니다.

환경설정 — 각 항목에 무엇을 넣나

필수 꼭 필요   권장 넣으면 좋음   선택 필요할 때만

네이버 로그인 ID · 비밀번호필수
블로그에 임시저장·발행할 때 자동 로그인에 사용합니다. 비밀번호는 보안 저장을 선택하면 파일이 아니라 macOS 키체인 / Windows 자격 증명 저장소에만 보관됩니다.
블로그 ID선택
로그인 ID와 블로그 주소가 다를 때만 입력합니다. 같으면 비워 두세요.
Google AI Studio API Key선택
AI로 자동 글쓰기에 사용합니다. aistudio.google.com/app/apikey에서 무료로 발급합니다. 안 쓰고 '프롬프트(복사)' 방식으로 작업하면 비워도 됩니다.
Kakao REST API 키권장
매물 주소·좌표와 주변 시설(입지) 정보 조회에 사용합니다. developers.kakao.com에서 앱을 만들고 발급합니다.
Kakao JavaScript 키선택
프로그램 안의 지도·로드뷰 표시에 사용합니다. 카카오 콘솔의 JavaScript SDK 허용 도메인에 http://localhost:8765를 등록해 주세요.
공공데이터포털 서비스키선택
건축물대장(사용승인일·층수·구조 등) 조회에 사용합니다. data.go.kr에서 '건축물대장정보 서비스'를 신청해 발급합니다.
문의번호권장
블로그 글의 중개사무소 정보 표에 표기됩니다.
중개사무소 정보권장
상호(사무소명)·대표 공인중개사·등록번호·소재지·전화·휴대전화를 넣습니다. 블로그 글 하단의 중개사무소 표에 표기되어 공인중개사법 표시·광고 규정을 지키는 데 쓰입니다. 체크를 해제하면 블로그에 표기하지 않습니다.
포스팅 방식 · 공개 범위 · 발행 카테고리선택
기본은 임시저장(안전)입니다. 발행을 고르면 즉시 등록되며, 이때 공개 범위(전체공개/비공개)와 발행 카테고리(블로그의 카테고리 이름과 정확히 일치)를 지정해야 합니다. 카테고리가 블로그에 없으면 발행하지 않고 임시저장까지만 진행합니다.
AI 자동 글쓰기 엔진 · Claude 키선택
자동 글쓰기 엔진을 Gemini 또는 Claude 중 고릅니다. Claude를 쓰려면 Anthropic API 키를 함께 입력합니다.
이실장 ID · 비밀번호선택
이실장 연동을 쓸 때만 입력합니다. 안 쓰면 비워 두세요.
