🏠 빠른 시작 안내

네이버 블로그 매물 자동화 프로그램을 처음 쓰는 분을 위한 3분 가이드입니다.

이 안내의 화면은 새로 바뀐 디자인을 기준으로 찍은 것입니다. 화면 속 폴더 경로와 아이디는 촬영용 예시이며, 실제로는 내 컴퓨터의 경로와 내 계정이 표시됩니다.

준비물

크롬(Chrome)이 설치돼 있어야 합니다(네이버 자동화에 사용). 설치본(setup.exe)으로 받은 경우 파이썬은 필요 없습니다. 소스 폴더로 직접 실행하는 경우에만 파이썬 3.11 이상이 필요하며, 없으면 python.org에서 설치하세요.
🪟 Windows (설치본)🍎 macOS (소스 실행)

1단계 · 설치 (Windows · 설치본)

1

setup.exe 더블클릭 → 설치

받은 vibe-blogpost-free-setup.exe를 더블클릭하면 설치가 진행됩니다 (관리자 권한 필요 없음). 설치가 끝나면 시작 메뉴와 바탕화면에 “네이버 블로그 매물 자동화” 아이콘이 생깁니다.

🍎 macOS는 소스 폴더로 실행합니다: scripts 폴더의 setup.command로 한 번 설치한 뒤, run.command를 더블클릭하세요. "확인되지 않은 개발자" 경고가 나오면 파일을 오른쪽 클릭 → 열기로 실행합니다.

2단계 · 프로그램 켜기

2

아이콘으로 실행

Windows: 시작 메뉴 또는 바탕화면의 “네이버 블로그 매물 자동화” 아이콘 클릭 (시작 메뉴 검색창에 “네이버” 또는 “vibe”를 쳐도 바로 나옵니다).
macOS: run.command 더블클릭.
아래 화면이 뜨면 준비가 끝난 것입니다.

화면 읽는 법 — 세 군데만 보면 됩니다

  1. 맨 위 머리띠 — 프로그램 이름과 전체 작업 순서(매물정보 → 주변 조사 → 글 작성 → 썸네일 → 네이버 임시저장)가 적혀 있습니다.
  2. 왼쪽 실행 설정 — 매물번호 칸과 1·2·3번(주황) 버튼, 그 아래 4·5번(흰색, 선택) 버튼이 세로로 놓입니다. 위에서 아래로 누르면 됩니다. 누르는 동안에는 주황빛으로, 끝나면 ✓ 표시가 붙은 초록색으로 바뀝니다.
  3. 오른쪽 결과 검토 — 내 매물 · 매물 조사 메모 · 프롬프트(복사) · blog자료 · 이미지 · 환경설정 · ⚙ 고급 탭이 있습니다. 단계를 실행하면 해당 탭으로 자동으로 넘어갑니다.

3단계 · 키 입력 (처음 한 번)

3

환경설정 탭

환경설정 탭에서 네이버 로그인 정보와 필요한 API 키를 넣고 저장합니다. AI 자동 글쓰기를 안 쓸 거면 Google 키는 비워도 됩니다. 맨 위 “사용 버전” 줄에서 지금 무엇이 준비됐고 무엇이 비어 있는지 한눈에 확인할 수 있습니다.

4단계 · 글 만들고 올리기

4

매물번호 → 조사 → AI 글쓰기 → 포스팅

① 매물번호 입력(또는 내 매물 탭에서 더블클릭) → 1. 매물 조사하기
② 2. AI로 자동 글쓰기 → 제목·본문·해시태그 자동 생성
③ 이미지 탭에서 대표 이미지와 본문 카드 확인
④ 내용 확인 후 3. 블로그로 포스팅

작업 흐름 자세히

  1. 좌측에서 매물번호를 직접 입력하거나, 내 매물 탭에서 정리해 둔 매물 목록 CSV 폴더를 지정하고 매물을 더블클릭하면 1. 매물 조사하기가 실행됩니다. 이때 네이버 매물 내용은 물론 건축물대장 정보와 주변 입지 정보까지 함께 가져옵니다.
  2. 2. AI로 자동 글쓰기를 누르면 미리 설정된 기준에 따라 blog자료 탭에 블로그 제목·본문·해시태그가 만들어집니다.
  3. 이미지 탭에서 디자인 템플릿(클래식·모던·볼드·포토)과 색상 프리셋을 고르면 대표 이미지(썸네일)가 만들어집니다. 체크를 켜 두면 본문 카드도 함께 만들어져 글에 들어갑니다.
  4. 3. 블로그로 포스팅을 누르면 자동으로 네이버에 로그인하고 정해진 카테고리에 올립니다.
  5. (선택) 대신 4. 프롬프트 생성으로 본문용·이미지용 프롬프트를 만들어, 다른 AI 프로그램으로 제목·본문·이미지를 제작해 올 수도 있습니다.
  6. (선택) 그 결과를 5. 결과 붙여넣기로 넣어 본문과 이미지를 완성한 뒤 블로그로 포스팅하는 방법도 있습니다.
✅ 기본은 임시저장이라 글이 바로 공개되지 않습니다. 발행(전체공개)은 환경설정에서 발행 모드를 켜고 카테고리 이름을 정확히 넣어야 진행됩니다.
🔒 다른 사람에게 줄 때는 설치본(setup.exe)만 주면 됩니다. 설치본에는 개인 키·계정· 로그인 세션이 들어 있지 않습니다. 설치 후 내 로그인·설정·생성물은 각자 PC의 사용자 폴더(%LOCALAPPDATA%\vibe-blogpost-free)에 저장되어 재설치·업데이트에도 보존됩니다. (소스 폴더째로 줄 때는 .env, config/user_settings.json, data/browser-profile를 빼고 주세요.)

필수 꼭 필요   권장 넣으면 좋음   선택 필요할 때만

네이버 로그인 ID · 비밀번호필수
블로그에 임시저장·발행할 때 자동 로그인에 사용합니다. 비밀번호는 보안 저장을 선택하면 파일이 아니라 macOS 키체인 / Windows 자격 증명 저장소에만 보관됩니다.
블로그 ID선택
로그인 ID와 블로그 주소가 다를 때만 입력합니다. 같으면 비워 두세요.
Google AI Studio API Key선택
2. AI로 자동 글쓰기에 사용합니다. aistudio.google.com/app/apikey에서 발급받습니다. 안 쓰고 '프롬프트(복사)' 방식으로 작업하면 비워도 됩니다.
Kakao REST API 키권장
매물 주소·좌표와 주변 시설(입지) 정보 조회에 사용합니다. developers.kakao.com에서 앱을 만들고 발급합니다.
Kakao JavaScript 키선택
프로그램 안의 지도·로드뷰 표시에 사용합니다. 카카오 콘솔의 JavaScript SDK 허용 도메인에 http://localhost:8765를 등록해 주세요.
공공데이터포털 서비스키선택
건축물대장(사용승인일·층수·구조 등) 조회에 사용합니다. data.go.kr에서 '건축물대장정보 서비스'를 신청해 발급합니다.
문의번호권장
블로그 글의 중개사무소 정보 표에 표기됩니다.
중개사무소 정보권장
상호(사무소명)·대표 공인중개사·등록번호·소재지·전화·휴대전화를 넣습니다. 블로그 글 하단의 중개사무소 표에 표기되어 공인중개사법 표시·광고 규정을 지키는 데 쓰입니다. 체크를 해제하면 블로그에 표기하지 않습니다. 여기 넣은 상호·연락처는 이미지 탭의 '사무소명·연락처를 썸네일에 표시' 체크를 켤 때 대표 이미지에도 함께 들어갑니다.
포스팅 방식 · 공개 범위 · 발행 카테고리선택
기본은 임시저장(안전)입니다. 발행을 고르면 즉시 등록되며, 이때 공개 범위(전체공개/비공개)와 발행 카테고리(블로그의 카테고리 이름과 정확히 일치)를 지정해야 합니다. 카테고리가 블로그에 없으면 발행하지 않고 임시저장까지만 진행합니다.
AI 자동 글쓰기 엔진 · Claude 키선택
자동 글쓰기 엔진을 Gemini 또는 Claude 중 고릅니다. Claude를 쓰려면 Anthropic API 키를 함께 입력합니다.
이실장 ID · 비밀번호선택
이실장 연동을 쓸 때만 입력합니다. 안 쓰면 비워 두세요.
각 API의 사용 한도와 요금 조건은 제공사 정책에 따라 달라지므로, 발급받은 콘솔에서 직접 확인해 주세요. 환경설정의 사용량 확인 버튼이 해당 페이지로 바로 이동합니다.
