# 네이버 블로그 매물 자동화 — 사용설명서

네이버 매물정보·Kakao 입지·건축물대장 자료를 모아 블로그 원고와 대표 이미지를 만들고, 네이버 블로그에 임시저장 또는 발행까지 해 주는 macOS·Windows용 로컬 프로그램입니다. 모든 처리는 사용자 PC에서 이루어지며, 비밀번호·API 키·쿠키 같은 민감정보는 외부로 전송되지 않습니다.

---

## 1. 처음 한 번만 — 설치

프로그램을 처음 받은 뒤 **한 번만** 설치 과정을 거칩니다. 설치는 프로그램이 사용할 파이썬 가상환경(.venv)을 만들고 필요한 부품을 내려받는 작업입니다.

**Windows**

1. 압축을 풀어 나온 폴더를 원하는 위치(예: 문서 폴더)에 둡니다.
2. `scripts` 폴더 안의 `setup.bat`를 더블클릭합니다. 검은 창이 뜨고 자동으로 설치가 진행됩니다.
3. "설치가 끝났습니다"가 보이면 창을 닫습니다.

**macOS**

1. 압축을 풀어 나온 폴더를 원하는 위치에 둡니다.
2. `scripts` 폴더 안의 `setup.command`를 더블클릭합니다. (처음에는 "확인되지 않은 개발자" 경고가 날 수 있습니다. 이때는 파일을 마우스 오른쪽 클릭 → **열기**를 선택하면 실행됩니다.)
3. 설치가 끝나면 창을 닫습니다.

> 설치에는 인터넷 연결이 필요합니다. 파이썬이 없다면 먼저 [python.org](https://www.python.org/downloads/)에서 설치해 주세요. 파이썬 3.11 이상을 권장합니다.

---

## 2. 실행

- **Windows**: 폴더 안의 `run.bat`를 더블클릭합니다.
- **macOS**: 폴더 안의 `run.command`를 더블클릭합니다.

프로그램이 잘못된 파이썬으로 실행되어도 자동으로 올바른 가상환경(.venv)으로 다시 시작하므로, 대표 이미지가 정상적으로 만들어집니다.

배포용 실행파일(.exe)로 받은 경우에는 설치 과정 없이 실행파일만 더블클릭하면 됩니다.

---

## 3. 최초 1회 — 환경설정(키 입력)

`환경설정` 탭에서 아래 값을 입력하고 저장합니다. 매물에 따라 필요한 항목만 넣어도 동작합니다.

- **Google AI Studio API Key** — AI 자동 글쓰기를 쓸 때만 필요합니다. 없으면 '프롬프트(복사)' 방식으로 진행합니다.
- **Kakao REST API 키** — 주변 시설·입지 조사에 사용합니다.
- **Kakao JavaScript 키** — 프로그램 안 지도·로드뷰 표시에 사용합니다. 카카오 콘솔의 허용 도메인에 `http://localhost:8765`를 등록해 주세요.
- **공공데이터포털 서비스키** — 건축물대장 표제부 조회에 사용합니다.
- **네이버 로그인 ID / 비밀번호 / 블로그 ID** — 임시저장·발행에 사용합니다. 로그인 ID와 블로그 ID가 같으면 블로그 ID는 비워도 됩니다.
- **문의번호·중개사무소 정보** — 블로그 글의 중개사무소 표기에 사용합니다.
- (선택) 이실장 ID·비밀번호.

각 키는 발급처 링크와 사용량 확인 버튼이 환경설정 안에 함께 있습니다.

---

## 4. 화면 구성(탭)

- **내 매물** — 지정한 CSV 폴더의 매물 목록을 보여 줍니다. 한 번 클릭하면 매물번호가 채워지고, 더블클릭하면 곧바로 매물 조사가 실행됩니다.
- **매물 조사 메모** — 수집한 매물·입지·건축물대장 자료가 하나로 정리되어 표시됩니다.
- **프롬프트(복사)** — 외부 AI(ChatGPT·제미나이 등)에 붙여넣을 블로그 글/이미지 프롬프트를 만들어 줍니다. 각 소제목의 안내대로 복사해서 사용합니다.
- **blog자료** — 최종 제목·본문·해시태그를 넣고 다듬는 곳입니다. 외부 AI 결과를 여기에 붙여넣습니다.
- **이미지** — 대표 이미지의 색상·문구 배치 프롬프트를 편집하고, 로컬 대표 이미지를 미리 볼 수 있습니다.
- **환경설정** — 위 3번의 키·계정·게시 설정을 관리합니다.
- **⚙ 고급** — 지도·로드뷰, 문제 해결·고급 설정, 기본 글 작성 프롬프트, 실행 로그가 들어 있습니다.

---

## 5. 작업 순서

프로그램은 두 가지 방식으로 글을 만들 수 있습니다. 둘 다 매물 조사로 시작하고, 블로그 포스팅으로 끝납니다.

### 방식 A — 프롬프트(복사) 방식 (기본, API 키 불필요)

1. 매물번호를 입력하고 **1. 매물 조사하기**를 누릅니다.
2. **2. 프롬프트 생성**을 누른 뒤 `프롬프트(복사)` 탭에서 블로그 글 프롬프트를 복사해, 평소 쓰는 AI(ChatGPT 등)에 붙여넣습니다.
3. AI가 만든 결과를 복사해 **3. 결과 붙여넣기**(또는 `blog자료` 탭)에 넣어 다듬습니다.
4. 필요하면 `이미지` 탭에서 **로컬 이미지 생성**으로 대표 이미지를 만듭니다.
5. **4. 블로그로 포스팅**을 눌러 임시저장(또는 발행)합니다.

### 방식 B — AI로 자동 글쓰기 (Google AI Studio 키 필요)

1. 환경설정에 Google AI Studio 키를 저장합니다.
2. 매물번호를 입력하고 **1. 매물 조사하기**를 누릅니다.
3. **(선택) AI로 자동 글쓰기**를 누르면 제목·본문·해시태그와 대표 이미지가 한 번에 만들어집니다.
4. `blog자료`에서 내용을 검토·수정합니다.
5. **4. 블로그로 포스팅**을 누릅니다.

> 두 방식 모두 같은 작성 기준(SEO·구조·필수 고지문)을 사용하므로 결과 형식이 동일합니다.

### 포스팅(임시저장 / 발행)

- 기본값은 **임시저장**입니다. 글이 즉시 공개되지 않으므로 안전합니다.
- **발행(전체 공개)**을 하려면 환경설정에서 발행 모드를 켜고 **발행 카테고리 이름**을 정확히 입력해야 합니다. 지정한 카테고리가 블로그에 없으면 발행하지 않고 임시저장까지만 진행합니다.
- 네이버 추가 인증·CAPTCHA가 뜨면 열린 Chrome 창에서 사용자가 직접 완료해야 합니다.

---

## 6. 만들어지는 파일

- 블로그 원고: `output/contents/blog_[매물번호].md`
- 대표 이미지: `output/thumbnails/thumbnail_[매물번호].png`
- 실행 원자료: `output/[날짜-시간-매물번호]/`

이 파일들은 사용자 PC 안에만 저장됩니다.

---

## 7. 보안

- 네이버·이실장 비밀번호는 파일이나 로그에 저장하지 않고, 선택 시에만 macOS Keychain 또는 Windows 자격 증명 저장소에 보관합니다.
- API 키는 Git에서 제외되는 로컬 `.env` 파일에 저장됩니다.
- 매물 조회용 쿠키·cURL은 프로그램 메모리(또는 OS 자격증명 저장소)에만 존재하며 파일·로그에 남기지 않습니다.
- 프로그램을 다른 사람에게 전달할 때는 `.env`, `config/user_settings.json`, `config/settings.yaml`, `data/browser-profile` 폴더를 절대 함께 전달하지 마세요(개인 계정·세션·키가 들어 있습니다).

## 8. 문제 해결

- **대표 이미지에 글자가 없어요** → 프로그램을 껐다가 `run.command`(mac)·`run.bat`(win)로 다시 켜 주세요. 잘못된 파이썬으로 실행되면 대표 이미지의 글자가 빠질 수 있는데, 최신 버전은 자동으로 올바른 환경으로 재실행합니다.
- **네이버가 매물 조회를 계속 막아요(403·429)** → 프로그램이 자동으로 재시도하고, 그래도 안 되면 숨겨진 Chrome으로 공개 화면을 읽습니다. 그래도 실패하면 `문제 해결·고급 설정` 탭 안내에 따라 개발자도구에서 요청을 **Copy as cURL**로 복사해 붙여넣습니다.
- **AI 자동 글쓰기가 안 돼요** → Google AI Studio 키가 없거나 무료 한도를 초과하면 수집 자료 기반 로컬 초안으로 자동 전환됩니다.
- **설치가 안 돼요** → 파이썬 3.11 이상이 설치되어 있는지 확인하고, `scripts/setup` 파일을 다시 실행해 주세요.

---

## 9. 비용

- 매물 조사(1단계)와 대표 이미지 생성(로컬)은 외부 유료 API를 호출하지 않습니다.
- AI 자동 글쓰기는 사용자가 넣은 Google AI Studio 무료 등급 키만 사용하며, 콘텐츠 한 건당 텍스트 생성을 한 번만 호출합니다.
- 확실한 과금 방지가 필요하면 결제가 연결되지 않은 무료 등급 키만 사용하거나 Google 키를 비워 두세요.
